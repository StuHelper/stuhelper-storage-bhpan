# BHpan 适配接口

## 范围与来源

`bhpan` 是服务端 Go 适配库，提供北航云盘登录、容量、文件、上传、下载与分享操作。授权、凭据生命周期和贡献容量规则由调用方管理。模块职责见[接入设计](../design/storage-adapter.md)。

接口路径和字段参考[旧项目协议入口](https://github.com/StuHelper/StuHelper-legacy/tree/4c6d67a2fb8184e935d0aad9e33ce5c18fea6ac3/server/internal/modules/storage/bhpan)。实现与测试重新编写，不导入旧模块、复制其源码或复用其测试夹具。

本地账号登录参考供应商登录脚本中的 RSA 公钥、加密方式、CSRF 字段和登录响应。脚本地址及 SHA-256 保存在来源记录中。

本仓库依据实际观测维护供应商协议快照，覆盖适配库调用的操作。来源记录包含观测日期、参考提交和摘要。[接口快照](https://github.com/StuHelper/stuhelper-storage-bhpan/blob/develop/contracts/bhpan.openapi.json) · [来源记录](https://github.com/StuHelper/stuhelper-storage-bhpan/blob/develop/contracts/bhpan.source.json)

## 登录与会话

`Login` 明确使用北航 SSO。先取得 CAS execution 字段，提交用户名与密码，再完成云盘 OAuth challenge 和回调。登录成功要求取得云盘 token，并读取非空且每项 ID 有效的文档库列表。

`LoginLocal` 明确使用云盘本地账号。先以属性顺序无关的方式读取登录页面 `__NEXT_DATA__` 中的 challenge、CSRF 和设备信息，再用默认或服务端 `Config.LocalPublicKeyPEM` 覆盖的 RSA 公钥执行 PKCS#1 v1.5 加密，提交本地登录接口。回调完成后使用相同的文档库校验。

供应商登录脚本成功时用浏览器的 `window.location.replace` 打开 `redirect`。客户端接收单斜杠开头的根相对地址和同源 HTTPS 绝对地址，保留 OAuth 查询参数及同源中间跳转。最终响应须到达云盘的 `/anyshare/oauth2/login/callback`。

回调链拒绝 `//` 开头的地址、跨源目标、HTTP、用户信息、URL 片段和路径中的转义分隔符或反斜杠。目标检查失败返回 `local-callback` 操作和 `ErrDestination`，响应内容与地址不进入错误。

两种方式不自动回退。失败登录会清除之前的 token 和全部 cookie，`Close` 同样丢弃会话。库不保存密码、不重放登录请求。

HTTP 客户端拒绝跳转时，错误保留操作名和触发跳转的响应状态码。响应地址、位置头和正文不进入错误。未收到响应时状态码为 0。

遇到风险确认、图形验证码或双因素认证时返回 `ErrChallenge`，并通过 `ChallengeOf` 提供 `risk_confirm`、`captcha`、`mfa` 脱敏分类。仅当调用方通过 `LoginWithOptions` 显式传入用户风险确认授权时，才提交 CAS `continueForm` 续接；验证码与双因素始终拒绝自动提交。

`RefreshSession` 在已登录会话上显式请求刷新接口，更新 `client.oauth2_token` 并通过文档库读取核验有效性。会话过期时清理本地状态，临时故障或权限拒绝保留原错误类别。

## 文件与传输

`PersonalLibrary` 从供应商列表筛选唯一的 `user_doc_lib`。缺少个人库返回 `ErrNotFound`，存在多个个人库返回 `ErrProtocol`。回收站接口显式接收分页参数。

`Quota` 返回整个账号的 `Allocated`（分配量）与 `Used`（已用量），单位均为字节。任一字段缺失或为负数时返回 `ErrProtocol`。已用量超过分配量时保留原值，`Available()` 返回零。目录占用通过 `DirectorySize` 单独查询。

`Identity` 取得当前登录用户的供应商稳定标识，供上层识别账号故障域。只返回用户 ID，不保留姓名、邮箱或其他个人资料。缺少 ID、账号类型不是用户或授权失败时拒绝，不以文档库名称、登录别名或目录代替账号标识。

`FileInfo` 按稳定对象 ID 查询当前文件位置，供调用方核对正常文件、回收站文件与彻底删除。返回标识必须与查询一致，大小等必要字段缺失时拒绝。回收站列表同时保留供应商原位置字段，但不能假设它等于删除前的 GNS 地址。

创建、重命名、复制和移动使用供应商 `ondup=1`，不自动覆盖同名文件或转换失败。删除进入回收站；恢复与彻底删除必须使用回收站列表返回的标识，不能继续使用删除前的文件标识。

普通上传按申请上传、写入对象、确认文件三个步骤执行。对象 PUT 成功时可能没有 ETag；调用方仍须在写入成功后执行 `FinishUpload` 或 `FinishUploadResult`。后者返回确认后的文档标识与修订号。任何失败都不自动重复写请求；已创建但未完成的对象由调用方按返回状态处理。

声明长度为零的普通上传先确认输入为空，再发送 Content-Length: 0。输入流长度与声明长度不符时返回 `ErrInput`，本地读取失败直接返回源错误，超长流在完成末段发送前中止。

分片上传先读取供应商限制，再申请分片和逐片写入。`PartGrant` 只读公开分片号与本地授权到期上限。分片必须具有 ETag，完成请求使用有序连续的分片号、大小和 ETag。供应商返回的 multipart 响应包含签名请求与 XML；对象服务确认完成后才执行文件确认，HTTP 200 内的 XML 错误仍判定失败。

下载与归档下载直接写入调用方提供的 writer，归档单次最多请求 1000 个条目，写入端出错时原样返回下游错误。秒传预检查仅代表可能匹配，秒传提交必须确认成功并返回新文件的文档标识与修订号。调用方不能把部分字节当作完整文件。

分段下载 `DownloadRange` 与 `DownloadSharedRange` 在对象请求附带 `Range` 头，校验 `206 Partial Content`、`Content-Range` 与实收字节数，并返回总大小、内容类型与 ETag。

`ParseShareURL` 从匹配受信任 `CloudURL` 的完整分享链接提取并校验分享标识，`InspectShare` 匿名读取公开元信息（是否需密码、标题、到期时间与次数限制），不携带个人会话。

分享标识采用字符白名单防止路径穿越。提取码仅作为写入输入发送，查询结果只保留是否设密的布尔标记，JSON 输出不包含提取码或临时授权。

匿名分享解析使用独立 cookie jar，密码错误统一返回 `ErrCredentials`，共享目录兼容 `size: -1`，普通文件列表拒绝负数大小。目录列表及下载授权保留路由 cookie，对象存储请求不携带 cookie。

## 网络与错误

配置只接受 HTTPS origin，默认仅允许云盘对象地址。额外对象 origin 必须由服务端配置，端口也参与校验。HTTPS 默认端口 443 统一处理；URL 用户信息、片段、非授权地址均被拒绝，对象存储 `3xx` 重定向明确返回 `ErrDestination`。

对象上传仅附带签名要求的非空单值 Authorization、Content-Type 和 X-Amz-Date，下载授权禁止附带额外签名头。对象请求不携带个人 token 或 cookie。临时签名在本进程最多使用十分钟，到期返回独立的 `ErrGrantExpired`，不与账号会话失效混淆。

元数据响应最多读取 4 MiB，目录列表受同一响应上限保护。超限返回 `ErrProtocol`，读取中断返回 `ErrUnavailable`，调用方取消优先返回 context 错误。元数据请求默认总超时三十秒，对象流式读写将该超时用于响应头等待与单次读写空闲检测，总时长由调用方 context 控制。

请求仅读取会话快照时持有读锁，关闭客户端无需等待网络响应。

错误只包含细分操作名、HTTP 状态、错误类别、纯整型供应商子错误码和 `Retry-After` 退避时长，不包含账号、密码、签名地址、cookie 或供应商原始文本。对象存储请求按上传、分片、完成、下载和归档分别标记操作名。

401、403、404、409 分别保留会话失效、操作被拒、对象不存在和冲突状态，不统一解释成密码失效。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| BH-01 | SSO 必须完成云盘 token 与文档库验证；失败重登清除旧会话 |
| BH-02 | 本地账号通过 CSRF 与 RSA 加密提交一次，完成同源绝对或根相对回调后可读取身份、目录和容量。无效回调目标不会收到请求 |
| BH-03 | 交互验证、外站跳转、取消、无效或超限响应明确失败，错误不暴露敏感内容 |
| BH-04 | 返回供应商容量原值，已用量超过分配量时剩余为零；文件操作和回收站分页遵守供应商接口 |
| BH-05 | 上传与下载授权不携带个人会话，恶意 origin、签名头或重定向被拒绝 |
| BH-06 | 分片顺序、授权与 ETag 完整，对象完成失败时不确认文件 |
| BH-07 | 分享操作保持个人与分享会话隔离，临时 token 不进入 JSON |
| BH-08 | 秒传、归档下载和分享历史按供应商明确结果返回 |
| BH-09 | 当前账号标识经过类型和非空检查，过期与拒绝分别报告，不返回个人资料字段 |
| BH-10 | 文件元数据与查询的稳定标识一致，缺字段或负大小被拒绝，404 与 403 分别报告 |
| BH-11 | 分段下载校验 206 与 Content-Range，返回总长度与 ETag，保持个人与分享凭据隔离 |
| BH-12 | 显式会话续期更新并核验令牌，失效时清理会话而临时故障保留原状态分类 |
| BH-13 | 错误保留整型供应商码与 Retry-After，对象传输细分操作标识且不泄露原始文本 |
| BH-14 | 个人文档库严格筛选 user_doc_lib，秒传与完成上传返回文档标识及修订号，分片授权公开只读元数据 |
| BH-15 | 交互验证区分风险确认、验证码与双因素，仅在用户显式授权时续接 CAS 风险确认 |
| BH-16 | 分享链接解析校验受信任 CloudURL 与安全标识，免密预检隔离个人会话并返回公开元信息 |

场景与真实测试函数登记在 `module.json` 的 `scenario_tests`，由本仓检查验证。真实账号结果、服务端装配和部署状态见[实施状态](../development/bhpan.md)。
