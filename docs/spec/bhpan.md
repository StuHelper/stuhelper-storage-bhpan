# BHpan 适配接口

## 范围与来源

`bhpan` 是服务端 Go 适配库，提供北航网盘登录、容量、文件、上传、下载与分享操作。业务方负责授权、凭据生命周期和贡献容量规则。本库没有数据库、后台任务或平台 HTTP 路由，不自行作出学生资格与存储贡献结论。

接口路径和字段参考[旧项目协议入口](https://github.com/StuHelper/StuHelper/tree/4c6d67a2fb8184e935d0aad9e33ce5c18fea6ac3/server/internal/modules/storage/bhpan)。实现与测试重新编写，不导入旧模块、复制其源码或复用其测试夹具。

本地账号登录补充参考[供应商登录脚本](https://bhpan.buaa.edu.cn/oauth2/_next/static/chunks/pages/signin-c48cff0def79ace2ad81.js)。脚本提供 RSA 公钥、加密方式、CSRF 字段和登录响应约定；公钥属于协议材料。

供应商没有提供本次可用的版本化 OpenAPI。私有仓库维护观测到的[接口快照](https://github.com/StuHelper/stuhelper-storage-bhpan/blob/develop/contracts/bhpan.openapi.json)与[来源记录](https://github.com/StuHelper/stuhelper-storage-bhpan/blob/develop/contracts/bhpan.source.json)，记录观察日期、参考提交和摘要。该快照不代表供应商完整接口，也不是平台对外 API。

## 登录与会话

`Login` 明确使用北航 SSO。先取得 CAS execution 字段，提交用户名与密码，再完成网盘 OAuth challenge 和回调。最终必须取得网盘 token，并成功读取个人文档库，才返回登录成功。登录返回的用户中心页面不作为成功证明，也不需要跟随其 HTTP 跳转。

`LoginLocal` 明确使用网盘本地账号。先读取登录页面中的 challenge、CSRF 和设备信息，再用供应商 RSA 公钥执行 PKCS#1 v1.5 加密，提交本地登录接口。回调完成后使用相同的文档库校验。

两种方式不自动回退。失败登录会清除之前的 token 和全部 cookie，`Close` 同样丢弃会话。库不保存密码、不重放登录请求。出现风险确认、图形验证或二次认证时返回交互验证状态，交互流程尚未实现。

## 文件与传输

文档库、目录、容量、目录大小和回收站使用供应商实际值。容量减少导致已用量超过分配量时，保留这两个值，可用容量按零返回。回收站接口显式接收分页参数。

创建、重命名、复制和移动使用供应商 `ondup=1`，不自动覆盖同名文件或转换失败。删除进入回收站；恢复与彻底删除必须使用回收站列表返回的标识，不能继续使用删除前的文件标识。

普通上传按申请上传、写入对象、确认文件三个步骤执行。对象 PUT 成功时可能没有 ETag；调用方仍须在写入成功后执行 `FinishUpload`。任何失败都不自动重复写请求；已创建但未完成的对象由调用方按返回状态处理。

分片上传先读取供应商限制，再申请分片和逐片写入。分片必须具有 ETag，完成请求使用有序连续的分片号、大小和 ETag。供应商返回的 multipart 响应包含签名请求与 XML；对象服务确认完成后才执行文件确认，HTTP 200 内的 XML 错误仍判定失败。

下载与归档下载直接写入调用方提供的 writer。秒传预检查只表示可能匹配，不能证明文件已经创建；秒传提交必须返回明确成功。流式读写失败返回失败结果，调用方不能把部分字节当作完整文件。

分享创建、更新、删除、查询和解析使用独立接口。匿名分享解析使用独立 cookie jar，其短期 token 仅用于该分享的文件访问，不覆盖个人会话。分享句柄与上传状态的 JSON 输出不包含临时授权。分享元数据请求保留独立的路由 cookie；取得 token 后直接核验文件，不依赖在线编辑页面可用。

## 网络与错误

配置只接受 HTTPS origin，默认仅允许网盘对象地址。额外对象 origin 必须由服务端配置，端口也参与校验。HTTPS 默认端口 443 统一处理；URL 用户信息、片段、非授权地址和对象请求重定向均被拒绝。

对象上传仅附带签名要求的 Authorization、Content-Type 和 X-Amz-Date，下载仅使用下载授权。对象请求不携带个人 token 或 cookie。临时签名在本进程最多使用十分钟；这是本地上限，实际有效期仍由供应商决定。

元数据响应最多读取 4 MiB。默认每次 HTTP 请求超时三十秒，也接受调用方 context 取消。错误只包含固定操作名、HTTP 状态和错误类别，不包含账号、密码、签名地址、cookie 或供应商原始响应。401、403、404、409 分别保留会话失效、操作被拒、对象不存在和冲突状态，不统一解释成密码失效。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| BH-01 | SSO 必须完成网盘 token 与文档库验证；失败重登清除旧会话 |
| BH-02 | 本地账号使用独立登录入口、CSRF 与 RSA 加密，不发送明文密码字段 |
| BH-03 | 交互验证、外站跳转、取消、无效或超限响应明确失败，错误不暴露敏感内容 |
| BH-04 | 容量、文件操作和回收站分页遵守接口字段，过量使用不会形成负可用量 |
| BH-05 | 上传与下载授权不携带个人会话，恶意 origin、签名头或重定向被拒绝 |
| BH-06 | 分片顺序、授权与 ETag 完整，对象完成失败时不确认文件 |
| BH-07 | 分享操作保持个人与分享会话隔离，临时 token 不进入 JSON |
| BH-08 | 秒传、归档下载和分享历史按供应商明确结果返回 |

场景与真实测试函数登记在私有 `module.json` 的 `scenario_tests`，由本仓检查验证。真实账号结果、服务端装配和部署状态见[实施状态](../development/bhpan.md)。
