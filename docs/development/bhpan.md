# BHpan 实施状态

## 当前交付

stuhelper-storage-bhpan 以 AGPL-3.0-only 公开提供独立 Go 存储适配库、观测接口快照、来源摘要、场景清单和标准输入验证程序。CI 的 `BHpan checks` 执行依赖边界、文档、协议、Go race、vet 与独立构建。

实现范围为 SSO 与网盘本地账号登录、稳定账号标识、文档库与容量、文件及回收站、普通与分片上传、下载、秒传、归档下载和分享。旧项目只作为接口线索；实现、错误处理、会话隔离和测试均独立维护。

## 迁移范围

实现从本任务 campus-adapters 工作树迁到独立仓库，Go 包移至仓库根目录。CLI 改用新导入路径，测试与契约引用同步调整。八个运行时代码文件与迁出提交逐字节一致，来源提交与文件摘要保存在 migration-source.json。

初始迁移保留原协议行为。当前新增稳定账号标识与文件标识查询，观测契约更新到 0.2.0，版本 tag 尚未发行。字段来源包括[供应商文档](https://developers.aishutech.com/napi/documents/307)和本任务获准账号的观测。

## 验证状态

当前通过 Go race、vet、独立构建、协议请求与 OpenAPI 字段校验、十个场景映射、来源摘要、文档及 Actions 检查。BH-09 验证账号标识与权限错误，BH-10 验证文件身份、必要字段及不存在；与存储核心的装配验证分别记录。

2026-10-25 使用本任务授权的两个账号复验。账号一走北航 SSO，账号二走网盘本地登录；账号标识、密码、token 和个人目录内容未写入仓库或验证记录。

## 剩余工作

2026-10-26 两种登录均通过只读复验。token cookie 未给出 Max-Age 或 Expires，也不是可直接读取到期声明的 JWT。初始及闲置十二分钟后的刷新请求均返回 200，token 未改变，受保护读取成功；会话均在十五分钟内销毁。

该结果仅验证短时可用，尚未测到真实到期，也未证明跨期续期或重启恢复。当前用户查询接口在两账号上均返回有效用户标识，观测未记录姓名、邮箱、标识值或令牌。长期授权材料保留规则仍由使用方另行明确。

当日另以两账号复验普通文件生命周期并清理临时目录。本地登录账号验证稳定文件 ID 可追踪回收站位置，彻底删除后返回 404。回收站原路径包含名称，不能直接用它推断原文件 ID 或证明永久删除。

业务调用方仍需实现服务端授权、凭据保管、贡献容量与期限、操作审计和可靠任务恢复。交互验证续接与自动会话续期尚未实现。模块不承担这些业务职责，不把本次适配测试计作完整存储贡献验收。

接口语义见[适配规格](../spec/bhpan.md)，本地与真实验证入口见[使用指南](../guide/bhpan.md)。
