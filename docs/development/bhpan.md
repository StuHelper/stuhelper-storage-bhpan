# BHpan 实施状态

## 当前交付

stuhelper-storage-bhpan 以 AGPL-3.0-only 公开提供独立 Go 存储适配库、观测接口快照、来源摘要、场景清单和标准输入验证程序。CI 的 `BHpan checks` 执行依赖边界、文档、协议、Go race、vet 与独立构建。

实现范围为 SSO 与网盘本地账号登录、文档库与容量、文件及回收站、普通与分片上传、下载、秒传、归档下载和分享。旧项目只作为接口线索；实现、错误处理、会话隔离和测试均为本次编写。

## 迁移范围

实现从本任务 campus-adapters 工作树迁到独立仓库，Go 包移至仓库根目录。CLI 改用新导入路径，测试与契约引用同步调整。八个运行时代码文件与迁出提交逐字节一致，来源提交与文件摘要保存在 migration-source.json。

本次迁移重跑独立模块检查、依赖边界和外部 Go 消费方编译。供应商请求实现没有改动，真实账号结果沿用下表，不把本地迁移检查表述为新一轮真实网盘验收。

## 验证状态

本地检查通过 Go race、vet、独立构建、协议请求与 OpenAPI 字段校验、八项场景映射、来源摘要、文档及 Actions 检查。架构仓库的任务分支已将本仓独立登记到 Mani，并保持 campus-adapters 的学校接入职责。

2026-10-25 使用本任务授权的两个账号复验。账号一走北航 SSO，账号二走网盘本地登录；账号标识、密码、token 和个人目录内容未写入仓库或验证记录。

| 验证范围 | 账号一 | 账号二 |
| --- | --- | --- |
| 登录、文档库、容量和目录读取 | 通过 | 通过 |
| 普通上传、下载与 SHA-256 核验 | 通过 | 通过 |
| 重命名、复制、移动、删除、恢复和彻底删除 | 通过 | 通过 |
| 20 MiB 首片与末片上传、完成和内容核验 | 通过 | 通过 |
| 密码分享、更新、查询、匿名下载与撤销 | 通过 | 通过 |
| 本次临时目录清理 | 通过 | 通过 |

秒传、归档下载、分享历史和共享目录遍历已通过本地协议夹具，尚未做真实账号验收。自动测试不使用真实账号。本次交付未装配正式 backend，未发行或部署。仓库与分支交付状态由任务结果单独说明。

## 剩余工作

业务调用方仍需实现服务端授权、凭据保管、贡献容量与期限、操作审计和可靠任务恢复。交互验证续接与自动会话续期尚未实现。模块不承担这些业务职责，不把本次适配测试计作完整存储贡献验收。

接口语义见[适配规格](../spec/bhpan.md)，本地与真实验证入口见[使用指南](../guide/bhpan.md)。
