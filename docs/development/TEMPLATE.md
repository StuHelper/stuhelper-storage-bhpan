# 开发工作主题

按[维护约定](https://github.com/StuHelper/stuhelper-next/blob/develop/docs/authoring.md)填写实际内容，删除不适用章节。规则、方案、进度与结果分别表达，确认依据沿用已有授权和实际讨论。

## 目标、范围与进度

写明本次交付范围与完成条件；正文标记待开始、进行中、已完成或已取消。

## 调研问题、来源与结论

针对影响决定的问题记录来源、版本、实验方法与限制，区分事实、观察和推断。

## 方案与确认依据

记录选定方案、依赖与实际确认，长期规则更新到设计/规格并在此链接。

## 任务与验收准备

按可独立验证的能力列任务与依赖，引用规格场景，说明验证环境和成功条件。

## 实际验证与交付

仅记录实际命令、环境、结果和证据；失败、未执行、部署与真实验收分别表达。

## 剩余事项与交接

写明剩余任务、阻塞、下一步和恢复上下文所需文件；处理原型与临时产物。
