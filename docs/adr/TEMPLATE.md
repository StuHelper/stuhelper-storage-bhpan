# 决策标题

按[维护约定](https://github.com/StuHelper/stuhelper-next/blob/develop/docs/authoring.md)填写实际内容，删除不适用章节。规则、方案、进度与结果分别表达，确认依据沿用已有授权和实际讨论。

## 背景与决定因素

说明需要作出选择的问题、目标、实际约束及当时可用的证据。

## 决策与确认依据

写明选择、适用范围与可定位的确认依据；尚未确认时保留 Draft/InReview。

## 备选与取舍

比较真实考虑过的候选、成本与风险，不为填满模板虚构备选。

## 后果与验证

说明决定带来的后续工作、限制和验收方式；实际结果由开发记录维护。

## 关联与替代

链接相关设计/规格；替代已有决定时注明范围，并更新旧 ADR 的状态与反向链接。
