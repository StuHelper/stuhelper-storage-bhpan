# 独立存储适配与业务接入

## 职责

本模块将 BHpan 的登录、容量、文件和传输协议封装为 Go 接口。它拥有独立仓库、Go module、版本、协议快照与测试，包名为 `bhpan`，导入路径为 `github.com/StuHelper/stuhelper-storage-bhpan`。

模块只依赖 Go 标准库。运行时需要访问 BHpan，选择 SSO 登录时还需要北航 SSO。Node.js、pnpm、工程工具和 hooks 只用于开发检查。供应商来自学校不改变本模块的存储职责。

campus-adapters 维护学校认证与教务数据接入。BHpan 自己完成访问网盘所需的登录，不依赖整个学校适配模块。协议代码与学校教务适配器分别维护和升级。

## 使用方边界

media 负责上传任务、对象版本、完整性校验、引用和文件可用状态，存储贡献业务负责容量、期限与退出处理。resources 等模块继续拥有资料访问与发布规则。BHpan 不读写这些模块的数据，也不决定调用方的业务权限。

公开业务模块只依赖自己定义的存储接口，接口返回业务所需的数据。backend 负责构造 BHpan 客户端并注入桥接实现，将供应商 ID、版本和错误转换成接口约定。本库源码公开，业务模块仍通过约定接口隔离供应商数据模型。

当前交付是可直接导入的协议库。media 的统一存储接口、桥接实现和 backend 正式装配尚未实现。调用方可先直接使用本包进行受控集成，后续业务接入遵循上述依赖方向。

## 运行方式

客户端保存一个账号的进程内会话，由使用方创建并在任务结束调用 `Close`。密码只在显式登录时传入。凭据保管、用户与存储账号绑定、授权范围和重试策略由使用方提供。

模块不监听 HTTP 端口，不启动后台服务或任务队列，也不要求数据库。独立版本不要求独立进程；可以静态编译进 backend，是否另行封装 HTTP/RPC 服务由实际部署需求决定。

文件传输使用 `io.Reader` 与 `io.Writer`，调用方可以接入文件、流或 HTTP 响应。操作接受 context，网络传输与超时由受控配置提供。调用方根据明确错误维护任务结果，不把请求失败当作空目录或文件已删除。

## 版本与兼容

新模块使用自己的 go.mod 和发布周期，不与 campus-adapters 共用版本。源码与协议来源分别记录：`migration-source.json` 记录本次实现迁出位置，`contracts/bhpan.source.json` 记录供应商接口参考。

正式消费者固定已验证版本或提交，使用 `GOWORK=off` 构建。本地联调可以使用 go.work 或临时 replace 指向本模块工作树；这些本机路径不进入正式消费方依赖。tag 和发布由 owner 授权。
